# Palestine3D — Backend

This repository contains the backend of the Palestine3D graduation project.  
It provides the API, authentication, roles system, marketplace, and notifications.

## ✨ Main Features
- Authentication (Login / Signup)
- User roles: Admin, Seller, Normal User
- Marketplace APIs
- Heritage content management
- Notification system
- PostgreSQL database with Prisma ORM

## 🛠️ Tech Stack
- NestJS
- PostgreSQL
- Prisma ORM
- TypeScript
